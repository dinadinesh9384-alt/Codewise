# Specialist Agents

Exactly eight specialist agents are defined here, in the canonical order:

1. `01_structure_analyzer` — deterministic; no LLM required.
2. `02_business_logic_analyst` — meaningful LLM reasoning.
3. `03_code_quality_analyst` — meaningful LLM reasoning.
4. `04_security_analyst` — meaningful LLM reasoning.
5. `05_migration_planner` — meaningful LLM reasoning.
6. `06_patch_author` — meaningful LLM reasoning.
7. `07_test_engineer` — meaningful LLM reasoning.
8. `08_review_agent` — meaningful LLM reasoning.

The two-digit prefix is for stable human-readable ordering. Internal agent IDs must remain independent of directory names (for example, `structure_analyzer`).
